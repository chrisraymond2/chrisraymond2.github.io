# Chris Raymond — personal website

Plain static site (HTML + one stylesheet), ready for GitHub Pages. No build step.

## Files

- `index.html` — home: bio, research interests, positions, contact
- `publications.html`, `talks.html`, `teaching.html`
- `style.css` — shared styles (light and dark mode)
- `cv.pdf` — your CV, linked from every page
- `images/profile.jpg` — profile photo (600×600)

## Before publishing

1. Check the content against your CV once more.
2. To update the CV, replace `cv.pdf` with the new version (keep the file name).

## Publish on GitHub Pages

#  1. Create a public repository named `<username>.github.io`.
#  2. Upload all files in this folder (keep the folder structure).
#  3. Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
#  4. Once you have a domain, enter it under Settings → Pages → Custom domain (GitHub adds a `CNAME` file for you).
